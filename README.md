# zlbdh

I am building small, file-based tools for making agent-assisted maintenance easier to audit.

## Current Focus

[Maintainer Harness](https://zlbdh.github.io/maintainer-harness/) is an open source control plane for maintainers using Codex or other coding agents.

It turns maintenance work into:

- change briefs
- impact maps
- scoped worker task cards
- validation evidence
- release gates
- security posture checks

The project is early and intentionally uses synthetic examples so maintainers can try the workflow without connecting private repositories.
